# Burger Dog

Pygame ile yazılmış özgün Burger Dog oyununun responsive tarayıcı sürümü.

- Masaüstü: Ok tuşları veya WASD, hız desteği için boşluk
- Mobil/tablet: Ekrandaki yön ve hız kontrolleri
- Özgün görseller, sesler, müzik, skor, can ve giderek hızlanan burger mekaniği korunmuştur

`burger_dog.py` özgün Python kaynağıdır.
